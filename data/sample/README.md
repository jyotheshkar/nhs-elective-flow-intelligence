# Sample data — DEMO SYNTHETIC

> **These files are NOT NHS England data.**

This directory contains a small, entirely **synthetic** dataset generated by
[`scripts/seed_demo.py`](../../scripts/seed_demo.py) from a seeded random process
(seed `20260101`).

It exists so the application can always be demonstrated — for example in an
environment with no outbound network access, or for a fast first run before the
~350 MB official ingest completes.

## What it contains

| | |
|---|---|
| Providers | 12 (fictional) |
| Treatment functions | 12 |
| Reporting months | 18 |
| Fact rows | 2,592 |
| `data_source_type` | `DEMO_SYNTHETIC` |

## Safeguards

Provider names are deliberately fictional — *Northgate University Hospitals NHS
Foundation Trust*, *Rivermead Healthcare NHS Trust*, and similar — so no synthetic
figure can ever be mistaken for a real organisation's published position.

Treatment function codes (`C_110`, `X05`, …) *are* the genuine NHS England codes: the
coding scheme is public reference data, and reusing it keeps the demo structurally
faithful to the real schema.

When this dataset is loaded, the application:

- stamps every row with `data_source_type = 'DEMO_SYNTHETIC'`
- displays a persistent banner: **"DEMO DATA — illustrative only"**
- labels the source as *"Synthetic demonstration dataset (not NHS England data)"* in
  the header, footer, methodology page and every CSV export

## Rebuild

```bash
python scripts/seed_demo.py                  # regenerate these files
python scripts/build_warehouse.py --demo     # build a warehouse from them
```

## For real data

```bash
make data
```
