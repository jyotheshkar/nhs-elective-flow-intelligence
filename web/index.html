02 / TRANSPARENT METHOD

The reasoning stays visible.

Interpretable calculations make a prototype easier to challenge, test and maintain.

01

Read the baseline

The browser edition uses fixed forecasts from regression fixtures. The original Python pipeline selects interpretable models using rolling-origin validation.

baseline(h) = fixture forecast at horizon h
02

Translate activity

Apply the chosen uplift to a complete recent activity window. Unknown activity is not treated as zero.

extra / month = activity × uplift / 100
03

Project the difference

Additional activity accumulates over the horizon. The waiting list is floored at zero.

scenario(h) = max(0, baseline(h) − h × extra)
